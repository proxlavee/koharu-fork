<Steps>
  <Step title="Choose a release">
    Open this fork's [latest GitHub release](https://github.com/proxlavee/koharu-fork/releases/latest) and run the 64-bit Windows NSIS installer. It is unsigned and may trigger Microsoft Defender SmartScreen. This fork does not publish macOS or Linux application binaries.

  </Step>
  <Step title="Let the runtime initialize">
    Launch Koharu and wait for the project browser. First launch can take longer while native packages download. Model files download when you first use the selected model.

    Runtime packages come from GitHub release assets, PyPI for CUDA, and AMD's repository for ROCm; model weights come from Hugging Face. Keep the app open while downloads finish; the activity center shows progress.

  </Step>
  <Step title="Create your first project">
    Follow the [quickstart](/en/quickstart) with one readable manga page. Check [hardware and runtimes](/en/hardware) if device initialization fails.
  </Step>
</Steps>

## Install updates

This unsigned build does not enable Tauri's signed updater. To update, close Koharu and run the newer installer from this fork's GitHub Releases page.

<Tip>
  Use a release build for translation work. Use the [development setup](/en/development/setup) when
  you want to change Koharu's code.
</Tip>
